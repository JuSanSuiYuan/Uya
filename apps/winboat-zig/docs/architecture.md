# WinBoat-Zig 架构文档

本文档详细介绍 WinBoat-Zig 的整体架构设计、系统组件、数据流程和技术选型。

## 1. 架构概览

WinBoat-Zig 采用模块化、分层的架构设计，实现了虚拟机管理、应用管理和系统监控等核心功能。整体架构分为命令行接口层、核心服务层、虚拟机运行时层和系统集成层四个主要部分。

## 2. 系统组件

### 2.1 命令行接口层 (CLI)

命令行接口层是用户与 WinBoat-Zig 交互的主要入口，提供了丰富的命令用于管理虚拟机、应用、配置和服务。

#### 2.1.1 VM 命令

- **功能**：管理虚拟机的生命周期，包括创建、启动、停止、暂停、恢复和删除等操作
- **主要命令**：create, start, stop, pause, resume, status, list, delete
- **实现文件**：`src/app/cli/vm.zig`

#### 2.1.2 App 命令

- **功能**：管理 Windows 虚拟机中的应用程序
- **主要命令**：start, stop, list, running, info
- **实现文件**：`src/app/cli/app.zig`

#### 2.1.3 Config 命令

- **功能**：管理 WinBoat-Zig 的配置
- **主要命令**：get, set, list, reset, validate
- **实现文件**：`src/app/cli/config.zig`

#### 2.1.4 Service 命令

- **功能**：管理 WinBoat-Zig 服务
- **主要命令**：start, stop, restart, status
- **实现文件**：`src/app/cli/service.zig`

### 2.2 核心服务层 (Core Services)

核心服务层实现了 WinBoat-Zig 的主要业务逻辑，包括容器管理、HTTP 服务、应用管理等功能。

#### 2.2.1 容器管理器 (Container)

- **功能**：管理虚拟机的生命周期，处理与虚拟化技术的交互
- **主要组件**：
  - VM 管理器：负责虚拟机的创建、启动、停止等操作
  - 快照管理器：负责虚拟机快照的创建、恢复和删除
  - 资源管理器：负责管理虚拟机的 CPU、内存、磁盘等资源
- **实现文件**：`src/container/*.zig`

#### 2.2.2 Guest Server

- **功能**：提供 HTTP API 服务，用于与 Windows 虚拟机通信
- **主要组件**：
  - HTTP 服务器：处理 API 请求和响应
  - 路由处理：路由到不同的处理函数
  - 健康检查：监控系统健康状态
  - 指标收集：收集 CPU、内存、磁盘等系统指标
- **实现文件**：`src/guest/server.zig`

#### 2.2.3 应用管理器 (Apps)

- **功能**：管理 Windows 虚拟机中的应用程序
- **主要组件**：
  - 应用启动器：启动应用程序
  - 应用监控器：监控应用程序的状态
  - 应用终止器：终止应用程序
- **实现文件**：`src/guest/apps.zig`

#### 2.2.4 配置管理 (Config)

- **功能**：管理 WinBoat-Zig 的配置系统
- **主要组件**：
  - 配置存储：存储和读取配置
  - 配置验证：验证配置的有效性
  - 配置加载：加载配置文件和环境变量
- **实现文件**：`src/config/*.zig`

#### 2.2.5 安全与认证 (Security)

- **功能**：提供认证和授权功能，保护系统安全
- **主要组件**：
  - API 密钥认证：验证 API 请求
  - 访问控制：控制对资源的访问
  - IP 白名单：限制允许的 IP 地址
- **实现文件**：`src/security/*.zig`

### 2.3 虚拟机运行时层 (VM Runtime)

虚拟机运行时层负责与虚拟化技术的交互，实现虚拟机的创建和管理。

#### 2.3.1 WinBox 运行时

- **功能**：使用 WinBox 技术管理 Windows 虚拟机
- **支持的功能**：虚拟机的创建、启动、停止、暂停、恢复、快照等
- **依赖技术**：KVM (Linux) 或 Hyper-V (Windows)
- **实现文件**：`src/runtime/winbox.zig`

#### 2.3.2 WSL 运行时

- **功能**：使用 Windows Subsystem for Linux 管理 Linux 子系统
- **支持的功能**：WSL 实例的创建、启动、停止等
- **依赖技术**：WSL 2
- **实现文件**：`src/runtime/wsl.zig`

### 2.4 系统集成层 (Integration)

系统集成层负责与操作系统和桌面环境的集成，提供更好的用户体验。

#### 2.4.1 UyaDE 集成

- **功能**：与 UyaDE 桌面环境的集成
- **集成点**：图标主题、颜色方案、通知系统
- **实现文件**：`src/integration/uyade.zig`

## 3. 数据流程

### 3.1 虚拟机管理流程

```
用户 → CLI (vm 命令) → 容器管理器 → 虚拟机运行时 → 虚拟机 (Windows/WSL)
```

### 3.2 应用管理流程

```
用户 → CLI (app 命令) → 应用管理器 → Guest Server → Windows 虚拟机 → 应用程序
```

### 3.3 HTTP API 请求流程

```
客户端 → Guest Server (HTTP) → 路由处理 → 相应的处理函数 → 响应
```

### 3.4 配置加载流程

```
应用启动 → 配置管理器 → 加载默认配置 → 加载配置文件 → 应用环境变量 → 验证配置 → 应用配置
```

## 4. 技术选型

### 4.1 开发语言

- **Zig**：主要开发语言，提供内存安全、高性能和跨平台支持

### 4.2 依赖库

- **std**：Zig 标准库，提供基础功能支持
- **yaml**：YAML 解析库，用于配置文件解析
- **http**：HTTP 服务器实现
- **winbox**：Windows 虚拟机管理库
- **winapi**：Windows API 绑定

### 4.3 虚拟化技术

- **KVM**：Linux 平台的虚拟化技术
- **Hyper-V**：Windows 平台的虚拟化技术
- **WSL 2**：Windows Subsystem for Linux 2

### 4.4 通信协议

- **HTTP/JSON**：API 通信协议
- **WinRM**：Windows 远程管理
- **RDP**：远程桌面协议


## 6. 数据模型

### 6.1 虚拟机 (VM)

```zig
type VM = struct {
    id: []const u8,
    name: []const u8,
    status: VMStatus,
    cpu: u8,
    memory: u32, // MB
    diskSize: u32, // GB
    created_at: i64,
    runtime: []const u8,
    config: VMConfig,
};

type VMStatus = enum {
    stopped,
    running,
    paused,
    starting,
    stopping,
    error,
};
```

### 6.2 应用程序 (App)

```zig
type App = struct {
    id: []const u8,
    name: []const u8,
    path: []const u8,
    description: ?[]const u8,
    icon: ?[]const u8,
    executable: bool,
};

type Process = struct {
    id: []const u8,
    app_id: []const u8,
    app_name: []const u8,
    pid: u32,
    started_at: i64,
    cpu_usage: f64,
    memory_usage: f64,
    status: ProcessStatus,
};
```

### 6.3 指标 (Metrics)

```zig
type Metrics = struct {
    cpu: CpuMetrics,
    ram: RamMetrics,
    disk: DiskMetrics,
    uptime: i64,
    timestamp: i64,
};

type CpuMetrics = struct {
    usage: f64, // 百分比
    frequency: u32, // MHz
    cores: u8,
};

type RamMetrics = struct {
    total: u32, // MB
    used: u32, // MB
    free: u32, // MB
    percentage: f64, // 百分比
};

type DiskMetrics = struct {
    total: u64, // GB
    used: u64, // GB
    free: u64, // GB
    percentage: f64, // 百分比
};
```

## 7. 可扩展性设计

### 7.1 接口抽象

WinBoat-Zig 使用接口抽象来实现可扩展性，主要的接口包括：

- **Runtime 接口**：抽象不同的虚拟化技术
- **Storage 接口**：抽象不同的存储后端
- **Logger 接口**：抽象不同的日志实现

### 7.2 插件系统

WinBoat-Zig 支持插件系统，可以通过插件扩展功能：

- **命令插件**：添加新的命令
- **运行时插件**：添加新的虚拟化后端
- **集成插件**：添加新的系统集成

### 7.3 事件系统

WinBoat-Zig 实现了事件系统，允许组件之间通过事件进行通信：

- **系统事件**：vm.created, vm.started, vm.stopped 等
- **应用事件**：app.started, app.stopped 等
- **系统事件**：system.shutdown, system.startup 等

## 8. 安全设计

### 8.1 认证与授权

- **API 密钥认证**：保护 HTTP API 接口
- **命令行权限**：根据操作系统用户权限限制命令执行
- **IP 白名单**：限制允许访问的 IP 地址

### 8.2 数据安全

- **敏感信息保护**：通过环境变量管理敏感配置
- **通信加密**：使用 SSL/TLS 加密 HTTP API 通信
- **输入验证**：严格验证用户输入，防止注入攻击

### 8.3 隔离与限制

- **资源限制**：限制虚拟机的 CPU、内存、磁盘等资源
- **网络隔离**：支持不同的网络模式，实现网络隔离
- **权限最小化**：以最小权限原则运行服务

## 10. 性能优化

### 10.1 内存管理

- **内存池**：使用内存池减少内存分配和释放的开销
- **预分配**：预分配常用资源，减少运行时分配
- **内存重用**：重用缓冲区和对象，减少内存碎片

### 10.2 并发处理

- **线程池**：使用线程池处理并发请求
- **异步 I/O**：使用异步 I/O 提高 I/O 性能
- **非阻塞通信**：使用非阻塞通信提高响应性能

### 10.3 缓存优化

- **结果缓存**：缓存频繁访问的结果
- **配置缓存**：缓存配置信息
- **元数据缓存**：缓存虚拟机和应用的元数据

## 11. 兼容性设计

### 11.1 跨平台支持

- **Linux/Windows/MacOS**：支持多平台运行
- **架构支持**：支持 x86_64 和 aarch64 架构

### 11.2 虚拟化技术兼容性

- **KVM/Hyper-V**：支持不同的虚拟化技术
- **WinBox/WSL**：支持不同的虚拟机管理方式

### 11.3 Windows 版本兼容性

- **Windows 10/11**：支持不同版本的 Windows
- **Windows Server**：支持 Windows Server 版本
